# Re:Cognize: Open-Set Comic Character Re-Identification

Code for the NeurIPS 2026 (Evaluations and Datasets Track) paper *Re:Cognize: Open-Set Comic
Character Re-Identification*: an evaluation harness that scores comic character re-identification
on one stream of crops in reading order, against four galleries.

Released under the MIT License. `Datasets/README.md` describes the corpora and their layout.
